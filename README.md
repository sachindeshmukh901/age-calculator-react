# Age Calculator

A small React + Vite app that calculates your exact age in years, months and days.

## 🚀 One-click launch

| | Link |
|---|---|
| **Live website** | `https://YOUR-USERNAME.github.io/age-calculator-react/` |
| **Open in StackBlitz (runs in browser)** | `https://stackblitz.com/github/YOUR-USERNAME/age-calculator-react` |

> Replace `YOUR-USERNAME` with your GitHub username.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech
React 18, Vite 5, deployed with GitHub Actions + GitHub Pages.
